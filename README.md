### 🚀 Sobre Mim
Sou um **Desenvolvedor de Software Pleno** (FullStack) com forte base em **UX/UI Design**. Minha especialidade é atuar no ciclo completo, criando desde protótipos de alta fidelidade até a implementação super performática em ecossistemas web e mobile.

- 💼 **Experiência Recente:** Como desenvolvedor FullStack Pleno na **DevMagic**, atuei no ecossistema SaaS de grande porte **Bloom by IMPACT** (gerenciamento ESG corporativo), entregando módulos de alta performance como dashboards com **+25.000 registros virtualizados**, back-end seguro em Node.js/PostgreSQL e liderando a manutenção mobile através do **React Native**.
- 🎓 **Formação Curricular:** Bacharelado em **Sistemas de Informação (UNIP)**, Especialização UX Design (XP Educação/IGTI), Curso Superior Desenvolvedor Web e robusta base em Infraestrutura de Redes / TCP-IP (SENAI).
- 🧠 **Diferenciais:** Unir **Design System corporativo e Código Limpo**. Tenho grande histórico estruturando interfaces altamente fieis com foco em desempenho, Acessibilidade (WCAG) e arquiteturas escaláveis. Além disso, incorporo ativamente **IAs Generativas** para atingir altíssima produtividade como desenvolvedor Pleno.

- **Engenharia Dirigida por IA:** Utilizo massivamente ferramentas como **Cursor, Claude e Antigravity Agent** em conjunto com meu raciocínio arquitetural para refatorar, desenvolver regras de negócio robustas e escalar sistemas entregando resultados extraordinários com altíssima produtividade de mercado.
- **Domínio da Alta Performance:** Implementação pragmática de padrões complexos, como **Virtualização no React**, lidando facilmente com renderização de **+25 mil campos em tempo real** sem queda de FPS e aliviando o main-thread.

- **Esteira de Qualidade:** Código limpo e versionado (GitFlow / GitHub / CI-CD), verificado (ESLint, Prettier, Husky, Conventional Commits) e protegido por testes automatizados E2E (Cypress) e Unitários (Jest).
